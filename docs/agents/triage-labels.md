# Triage Labels

skill は 5 つの triage の役割で話す。この file は、その役割をこの repo の issue tracker で使う label 名に対応させる。

| mattpocock/skills の label | この repo の label | 意味                                |
| -------------------------- | ------------------ | ----------------------------------- |
| `needs-triage`             | `needs-triage`     | maintainer が評価する必要がある     |
| `needs-info`               | `needs-info`       | 報告者からの追加情報を待っている    |
| `ready-for-agent`          | `ready-for-agent`  | 仕様が固まり、AFK の agent に渡せる |
| `ready-for-human`          | `ready-for-human`  | 人が実装する必要がある              |
| `wontfix`                  | `wontfix`          | 対応しない                          |

skill が役割で指示したとき（例:「AFK-ready の triage label を付ける」）は、この表の対応する label 名を使う。

使っている label 名が変わったら、「この repo の label」の列を直す。
